# 用户快速上手

[English](quickstart.md) · [工作台操作说明](../tools/capture_console/README.md)

适用于配套设备的 Ubuntu 24.04 x86_64 电脑。普通用户只需要安装程序、连接设备、开始使用，不需要配置 Python、ROS、源码路径或 Tracker 输入文件。

## 安装

1. 打开交付人员提供的下载链接，下载包含图形安装器的完整程序包并解压。
2. 双击解压目录中的 **Install-VisionTactile**，点击 **安装**。系统提示时输入本机管理员密码。
3. 等待显示 **安装完成**，点击 **打开工作台**。

首次安装需要联网，程序会自动下载并配置运行环境、相机驱动和配套 Tracker 依赖。安装界面显示当前进度，无需分别下载组件或复制命令。遇到错误时，点击“查看详细进度”，把提示交给维护人员；解决后可点“重试”。

以后从应用菜单中的 **Vision Tactile 采集工作台** 启动。图形安装器会将程序复制到本机固定位置，安装成功后可以删除下载、解压的目录。

旧版仅含 `install.sh` 的源码交付包不具备以上图形自动安装流程，应由维护人员更新交付包。

## 第一次使用

1. 连接本套相机、Tracker 接收器及所需手套设备。首次安装前已插入的接收器或串口设备，请重新插接一次，使访问权限生效。
2. 在 **设备 → 配置设备** 中确认启用的设备及其对应位置。运行路径自动填写；左右手、相机位置等实物对应关系需要按实际连接确认。
3. 需要 Tracker 时，打开 **标定与离线工具 → Tracker 初始化向导**，按窗口提示完成初始化与开机顺序。
4. 打开所需设备，确认实时预览正常，再开始录制。
5. 录制完成后进入 **档案** 查看数据和回放。

该包覆盖主采集工作台、相机及配套 Tracker。独立手势求解、许可手模型和专用标定环境属于可选交付内容，由维护人员预先配置。

安装完成表示软件环境已就绪；设备未连接或尚未初始化时，界面会提示对应状态。相机和触觉功能可以按已连接设备使用。

## 常见情况

| 情况 | 操作 |
| --- | --- |
| 安装进度较慢 | 首次环境下载和构建需要时间，保持联网，查看当前阶段即可 |
| 系统要求管理员密码 | 输入这台电脑的管理员密码；不需要提供 GitHub 令牌 |
| 程序提示已有驱动不兼容 | 将提示交给维护人员处理，避免覆盖已有工作环境 |
| 找不到或用错设备 | 检查连接，在“配置设备”确认实际设备及左右手、相机角色 |
| Tracker 没有位置数据 | 按初始化向导完成操作，确认使用的是与交付包配套的设备组 |

安装包应由维护人员随对应设备提供。免 GitHub 登录的下载入口由交付方配置；私有 GitHub 仓库属于维护端存储，不应作为普通用户必须注册、申请权限的步骤。
